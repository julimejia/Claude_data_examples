# ADR-0003 - architect decision in task:T-022

- Status: accepted
- Date: 2026-09-20
- Raised during: task:T-022
- Decided by: project owner via Telegram

## Context
T-022 fails on one test, tests/unit/test_demo_ui.py::test_generator_output_is_up_to_date, which runs tools/gen_demo_examples.py — a file that has never existed in any commit, is not on disk and is not stashed or ignored; everything else about the demo UI passes (630 tests). Attempt 3 (56f9637) rewrote 61 lines of public/examples.json in a different sort order (by case id rather than by filename, the order load_cases uses), proving a generator ran during the attempt but never landed, so the dev cannot persist a file under tools/ — a path-allowlist/stash wall, not a coding error, and a fourth retry fails the same way. Two design defects compound it: the test runs the generator with cwd=ROOT so it overwrites the tracked examples.json and leaves the tree dirty on failure (which the loop then committed), and neither FR-9 nor ACCEPTANCE.md requires byte-identical regeneration — gen_golden.py has no such test either. Options: (A) move the generator to scripts/gen_demo_examples.py and make the check regenerate into tmp_path and compare parsed JSON; (B) keep it in tools/ matching gen_golden.py, with you committing it rather than widening the dev's write scope into the directory that holds its own supervising harness; (C) delete the byte-equality test and rely on the two content tests that already prove every example maps to a golden case and matches the deterministic classification, accepting that T-022's 'generated by a script' AC is then only partly met. I recommend A with C's non-mutating principle; the blocking question is which directories the dev role may write, since scripts/ does not exist yet and T-023 and T-028 both need it.

## Decision
A — move the generator to `scripts/gen_demo_examples.py` and make the freshness check regenerate into a
temporary directory and compare parsed JSON, so it never writes into the working tree.

The decision is worked out, with the root cause, the consequences and the implementation contract for the
next T-022 attempt, in [ADR-0004](ADR-0004-generator-scripts-in-scripts-and-non-mutating-freshness-checks.md).
